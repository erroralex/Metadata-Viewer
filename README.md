# AI Metadata Viewer & Extractor

A modern, high-tech desktop application for extracting and managing generation parameters from AI-generated images. Built with **JavaFX**, this tool specifically targets workflows from **A1111**, **Forge**, **ComfyUI**, and **SwarmUI**.

---

## ✨ Key Features

- **Multi-Platform Extraction**  
  Robust parsing for PNG and JPEG metadata chunks generated by popular AI interfaces.

- **Drag & Drop Interface**  
  Simply drop an image into the portal to instantly reveal prompts, models, steps, seeds, and Loras.

- **Favorites System**  
  Save your most useful prompts to a local library with full persistence (JSON-based storage).

- **Modern AI Aesthetic**  
  A sleek **“Obsidian & Indigo”** dark theme designed for a professional developer experience.

- **Persistent Navigation**  
  A centralized admin-portal layout with a persistent sidebar for seamless multi-view management.

## 🚀 Getting Started

### Prerequisites

- Java 8  
  *(Liberica JDK “Full” recommended for built-in JavaFX support)*
- Maven 3.6 or higher

### Installation & Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/metadata-viewer.git
   ```

2. **Navigate to the project directory**

  ```bash
  cd metadata-viewer
  ```

3. **Build and run using Maven**

  ```bash
  mvn clean compile javafx:run
  ```
